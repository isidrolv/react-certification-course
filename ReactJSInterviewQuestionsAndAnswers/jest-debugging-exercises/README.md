# Ejercicios de depuración con Jest

Los archivos de `src/` son copias de los bloques **Código Fuente (Con Errores)** de `../react_ejercicios_depuracion.md`. No contienen las soluciones.

Las pruebas describen el comportamiento correcto y por diseño varias fallan inicialmente. Corrige únicamente los ejemplos y ejecuta `npm test` hasta que todo pase.

## Uso

```powershell
npm install
npm test
npm test -- ejercicio-01
```

Las pruebas simulan red, tiempo y alertas; no dependen de servicios externos.
